# Macro Binds

A separate macro hotkey menu for the supported Windows xdBot 2.7.7 build.

- **F8** opens the menu. No button is added to Pause.
- Search, assign a key, load a macro. Bindings save immediately.
- Does not turn Playback on. Use xdBot's Playback key yourself.
- Hides the success toast only for loads from this mod.
- Searches xdBot's macro and autosave folders, including subfolders, in the background.
- **Folder** adds a custom folder; **Auto** resets it. **Refresh** updates the list.

Requires the exact supported xdBot DLL; other builds are rejected.
