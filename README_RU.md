# Macro Binds 1.0.0

Отдельный Windows-мод для приложенного **xdBot 2.7.7**, GD **2.2081**, Geode **5.10.0+**. Собственные меню и бинды; SiliFork и ZCB Live не требуются.

## Как пользоваться

1. Открой **F8** или кнопку **Binds** в паузе.
2. Найди макрос поиском, нажми **Bind** и нужную клавишу, например **K**. Поддерживаются сочетания с Ctrl, Shift, Alt.
3. Закрой меню. Теперь K вызывает штатную загрузку этого макроса в XDBot. **Playback мод не включает и не переключает**; используй обычный бинд XDBot. Если Playback уже включён, он остаётся включённым.
4. **X** удаляет только бинд. Макрос остаётся на диске. **Load** загружает из меню, **Refresh** перечитывает список, **All / Bound** переключает фильтр.

Бинды сохраняются сразу, включая полный путь к файлу. Повторное назначение той же клавиши переносит её на выбранный макрос. Удержание не повторяет Load. Пока вводится текст или открыт другой диалог, макробинды не срабатывают. При открытии меню во время игры включается пауза.

F8 меняется в настройках **Macro Binds → Open Menu**. Там же находится **Enabled**. Назначенная нашему моду клавиша перехватывается раньше XDBot: K не должна одновременно включать его Frame Stepper. Не назначай на загрузку ту же клавишу, которой хочешь включать Playback.

## Откуда берётся список

XDBot не хранит все доступные макросы постоянно распакованными в RAM: его обычное меню строит список из папки **Macro Save Location**. Наше меню читает эту же настройку и папку, а затем через проверенные адреса в памяти вызывает родной загрузчик XDBot. Не сканирует всю память процесса и не опрашивает диск каждый кадр. Уже сохранённые бинды отсутствующих файлов остаются в списке красными, чтобы их можно было убрать или восстановить файл.

Уведомление **Macro Loaded** подавляется только при загрузке через Macro Binds. Ошибки и предупреждения остаются видимыми; обычная ручная загрузка через меню XDBot не изменена. Во время записи загрузка отклоняется, чтобы не затереть текущую запись.

## Получение .geode

Этот архив содержит **исходники**, а не готовый бинарник.

1. Помести содержимое папки `MacroBinds/` в корень нового GitHub-репозитория. Включи `.github/workflows/build.yml`.
2. Открой **Actions → Build Macro Binds → Run workflow** либо сделай коммит.
3. После успешной сборки скачай **Macro-Binds-Windows** и положи полученный `.geode` в `Geometry Dash/geode/mods/`.
4. Рядом должен быть тот самый приложенный `zilko.xdbot.geode`. Оригинальный файл XDBot менять не нужно.

Локально: Windows x64, Geode SDK 5.10.0, MSVC-совместимый clang-cl, Release:

```powershell
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_C_COMPILER=clang-cl -DCMAKE_CXX_COMPILER=clang-cl
cmake --build build --config Release
```

Перед конфигурацией укажи `GEODE_SDK`, установи Geode CLI и открой среду разработчика Visual Studio.

## Проверки и пределы совместимости

Проверены адреса, границы функций, места вызовов и импорты именно из приложенной DLL. Перед использованием мод сравнивает SHA-256 файла DLL, PE-параметры и байты функций в памяти. Другую сборку, даже с тем же номером 2.7.7, он отклоняет. Универсальной поддержки всех версий XDBot здесь нет.

На хосте прошли C++-тесты биндов, владения нажатием/отпусканием, подавления только нужного уведомления и проверки бинарного профиля. **Windows-сборка, интерфейс и выполнение внутри Geometry Dash здесь не проверялись**. Для первого игрового теста используй сохранённый макрос: Load должен сменить макрос без автозапуска и без уведомления; штатный бинд Playback должен продолжать работать.

Конфигурация хранится штатным механизмом Geode в данных мода `sennot.macro_binds` (ключ `bindings`).

Исходники XDBot и его DLL в этом архиве не распространяются. Это отдельное неофициальное дополнение. Технические сведения о проверенной сборке: `docs/binary-profile.json`, `docs/bridge-notes.md`.
